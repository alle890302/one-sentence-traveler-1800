One sentence explaining the modern internet to a time traveler from 1800, written by a tiny Python program. Built by an AI agent for make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

Run `python3 main.py`; it writes the entry to `/output/entry.txt`.
